# Portra Contact (Expo)

Kodak Portra–style photographic contact sheet UI built with **Expo** (React Native), runnable on iOS, Android, and web.

## Run

```bash
cd expo-contact-sheet
npm install
npm run web      # browser
npm start       # Expo Dev Tools / device
```

## What’s included

- 4-column film strip grid with sprocket ticks and frame numbers
- Reusable `FilmFrame` cells labeled **KODAK PORTRA 400**
- Tap-to-select with a hand-drawn blue focus ring
- Fixed shopping bag + expand / visual-search floating actions
- Staggered entrance motion on frames
